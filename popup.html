Privacy & Data Handling

Your Data, Your Control

VaultBix is privacy-first. All detection happens locally in your browser.

100% Local Scanning

Pattern matching runs entirely in your browser using JavaScript. No cloud AI, no server processing.

What We Store (Locally Only)

Event type, timestamp, site domain, and category. Never the actual secret values.

What We NEVER Collect

  • Your prompts or messages
  • Actual secret values (API keys, passwords)
  • Browsing history
  • Analytics or telemetry

Network Requests

The only network request VaultBix makes is license key validation (Pro users). No prompt content is ever sent.
